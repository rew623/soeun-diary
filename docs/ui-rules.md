# 화면·동작 규칙 (새 화면·단추를 만들거나 화면 관련 고칠 때 확인)

- 맨 위(scrollY 0)에서 아래로 당겼다 놓으면 새로고침(.ptr 표시, 서비스 워커 새 버전 확인 뒤 location.reload — 배우자가 올린 것도 서버에서 새로 받음, 사용자 요청 2026.10.11). 아래 창·겹침 창·지도·보드 위에선 안 함
- 탭 화면(#app)을 좌우로 밀면 옆 탭으로 넘어감 (index.html 하단). 지도·수사 보드(#bwrap)·입력칸·사진 고르기 중·하위 화면(S.view)은 제외, 막고 싶은 칸엔 data-noswipe
- 사건 앨범: 앨범 칸엔 떠 있는 '+ 사진 올리기'(현장 사진첩 여러 장), 가족 칸엔 '+ 가족 사진'. 순서: 지난 오늘 → 100일 보고서 → 현장 사진첩 → 월별 증거 사진 → 최초 목격 → 미확인 사건. 칸과 사진첩 달 묶음은 접기 가능 (data-fold, localStorage soeun-fold). 사진첩은 가장 최근 달만 기본으로 펼침, 펼친 달·사진첩 맨 아래에도 접기 단추
- 파일 선택 칸(input type=file)은 #app 밖(body에 고정)이나 편집창(sheet) 안에 둘 것. 파일 창에서 돌아올 때 화면을 다시 그려 #app 안의 칸이 사라짐
- GitHub Pages 배포(pages build and deployment)가 GitHub 쪽 오류로 가끔 실패함. 실패한 job을 재실행하면 됨
- map-key.js를 바꾸면 sw.js VERSION도 올릴 것 (안 올리면 폰에 반영 안 됨)
- ★ 화면 이동(사용자 요청, 새 메뉴·화면을 만들 때마다 꼭 지킬 것): 안쪽 화면은 S.view='이름'으로 열면 index.html의 NAV가 그 전 화면(탭·안쪽 화면·앨범/예방접종/동네 탐문 칸 albumView·vacView·townView·스크롤 위치)을 저절로 기억하고, 닫기·돌아가기 단추와 휴대폰 뒤로가기는 goBack()(또는 단추에 data-act="back")으로 열기 전 화면 그 위치로 돌아감. 돌아가기에 S.view=''를 쓰지 말 것(그건 탭 이동처럼 기록을 비움). 새 안쪽 화면엔 맨 아래 '돌아가기' 단추를 둘 것
- 뒤로가기: 크롬은 화면을 만지기 전에 넣은 기록 칸을 건너뛸 수 있어, 앱을 열자마자 뒤로가기를 누르면 안내 없이 꺼질 수 있음. 놀이터 안 게임·룰렛·스티커(S.view play/fun)에서 뒤로가기는 도토리 놀이터로. 같은 포즈 촬영기·영상 녹화 화면도 뒤로가기로 닫힘(viewer.js popstate에서 POSECAM.close·MOVIE.close)
- 탭 밀기는 옆으로 스크롤되는 줄(overflow-x auto/scroll, 예: 동네 탐문 시간별 날씨) 위에서는 안 함 (그 줄을 넘김). 넘길 때는 새 탭을 먼저 그린 뒤 반대쪽에서 미끄러져 들어오게(끝까지 밀어낸 뒤 그리면 빈 화면이 잠깐 보임)
- html·body에 overscroll-behavior-y:none — 안드로이드의 늘어나는 스크롤 효과 때문에 아래 메뉴·떠 있는 단추가 같이 밀리던 것 막음
- 화면 확대(핀치 줌) 막음: viewport에 maximum-scale=1, user-scalable=no — 실수로 확대되면 아래 메뉴가 화면 밖으로 잘렸음(2026.10.11). 사진 확대는 크게 보기(viewer.js)에서
- 한글 줄바꿈: body에 word-break:keep-all + overflow-wrap:break-word (낱말 사이에서만 줄 바꿈, 사용자 요청). 좁은 단추는 그림 한 줄·글자 한 줄로
- 알림 띠(toast)는 z-index 100 (탐문 중 화면·촬영기 같은 겹침 창 위에도 보이게)
- 사진 고르기 칸은 모두 갤러리 앱 창(accept 'image/*,application/octet-stream', 사용자 요청 2026.10.11 — 설정의 '사진 올리기 기본 창'은 뺌, 앱 안 카메라 찍기만 capture). 사진이 아닌 파일은 걸러요. 참고: accept='image/*'뿐이면 크롬이 안드로이드 사진 선택 창(사진|컬렉션)을 띄움. 'image/*,application/octet-stream'으로 열면 파일 고르기 창 → 왼쪽 메뉴에서 갤러리 앱(앨범 폴더)·내 파일 (현장 사진첩 '📁 갤러리 앱·파일에서 고르기', 탐문 폼 '📁 갤러리 앱에서', ALBUM.pickFiles), 위치도 대개 그대로. 올리기 시작 알림에 '📍 위치 있는 사진 N장'
- 안드로이드는 갤러리에서 고른 사진(input type=file, 사진 선택기)의 GPS를 지워서 넘겨줌(개인정보 보호, 웹앱은 ACCESS_MEDIA_LOCATION을 못 받음) → 사진 위치는 EXIF에 기대지 말 것. 찍은 시각은 남으니 탐문 경로(walk.js)로 자리를 찾고, 앱 안 카메라로 찍을 땐 그때 위치를 붙임
- 속도(2026.10 점검): render()는 #app 전체를 다시 그리므로 연달아 여러 번 부르지 말 것 — 사진 주소 불러오기(loadPhotos)는 다 받은 뒤 한 번만 그림(예전엔 4장마다 그려 사진 400장이면 열 때 8초 버벅임). render 안이나 직후에 scrollY·scrollHeight·getBoundingClientRect 같은 배치 값을 읽으면 화면 전체 배치를 억지로 계산해 느려짐(staySave는 0.3초 뒤). 폰 사본 저장(saveCache)은 2초 모아서, 앱 내릴 때 바로 씀. 사진 칸 img는 loading=lazy decoding=async (수사 보드·성장 앨범 책은 레이아웃·인쇄 때문에 그대로). 글씨는 11px보다 작게 하지 않기
- canvas로 사진을 그려 저장하는 기능(사진관·영상·신문)은 Firebase 사진을 crossOrigin으로 불러와야 하고, 버킷에 CORS 설정이 있어야 함(storage-cors.yml, 오류 응답에만 붙는 CORS 헤더에 속지 말 것). CV.img: crossOrigin → fetch(cache reload)→blob → Storage SDK getBlob(window.__photoBlob) 순서. sw.js 사진 캐시는 cors + cache:'reload'로 받음. 안 되면 사진관은 '📱 폰에서' 고르기 안내. 사진 주소는 safeImg로 거른 것만
- 아래 창(sheet): 열려 있는 동안 html.shopen(overflow hidden)으로 뒤 화면(지도 등)이 안 움직이고, .sheet는 overscroll-behavior contain. 손잡이(맨 위 48px)나 맨 위까지 올린 내용에서 아래로 끌면 닫힘(지도·입력칸·data-noswipe 위는 제외). 적던 중(입력·칩·__app.sheetDirty())이면 바깥 누르기·뒤로가기·끌어내리기는 한 번은 막고 '한 번 더 하면 닫혀요'(2.5초 안 두 번째에 닫힘, softClose) — 닫기·취소 단추는 바로 닫힘. 같은 제목으로 다시 그리면 적던 중 표시 유지
- 조사는 받침에 맞춰 jo(낱말,'은','는') · joRo(낱말)('으로'/'로') — '(으)로·은(는)'처럼 쓰지 말 것 (index.html)
- 미확인 사건(최초 목격 체크리스트)은 제목이 조금 달라도 목격한 걸로(MILEK 정규식: '뒤집기 시도'→뒤집기, '까르르 웃음'→소리 내어 웃기)
- 확인창은 폰 기본 confirm/alert 말고 앱 모양 ask() 쓸 것 (index.html, `if(!await ask('지울까요?',{ok:'지우기',danger:true}))return`, 뒤로가기로 닫힘). 알림 띠(toast)는 크라프트 카드 + Jua. 글꼴은 Jua·Gowun Dodum만 (select도 상속)
- 성장 수사 첫 화면 방 그림 안엔 단추를 두지 않음(방이 좁아짐) — '🛋️ 방 꾸미기'는 방 바로 아래 오른쪽 가장자리에 걸친 작은 단추(.groomwrap .ghedit, 말풍선 안에 있으면 캐릭터가 하는 말 같아서 — 사용자 요청 2026.10.11). 방 단추는 누를 때 파란 표시 없음
- 소탭(.seg: 예방접종·영유아검진·발달 체크 / 앨범·가족·수사 보드 / 탐험 지도·날씨): 제목(h1) 바로 아래, 설명·캐릭터 말풍선보다 위 — 탭을 넘겨도 같은 자리(사용자 요청). 디자인은 크라프트 홈 + 고른 칸은 종이 스티커(분홍 테이프·빨간 밑줄), 그림 한 줄·글자 한 줄. 제목은 좁은 폰에서도 한 줄(clamp)
- 꾸밈(2026.10.11): 여는 화면은 깍정이를 쫓는 소은 탐정(.lchase), 탭을 바꾸면 아래 메뉴 아이콘이 톡(탭 바는 HTML이 같으면 다시 안 그림 $tab.__h), 제목 아래 발자국 줄(.vhead::after), 탭 맨 아래 '오늘의 수첩' 한 줄(noteFoot, 날마다), 깍정이를 따라잡으면 망토 펼쳐 날아가며 도토리 떨어뜨리는 장면(WANTED.fx, 추적 화면에 다시 보기), 숨은 도토리는 '깍정이가 떨어뜨린 도토리'. 알림 띠는 \n 줄바꿈(white-space:pre-line)
- 사건 앨범 도구 칸(.atools): 기념 사진관·성장 영상·소은일보·봉인된 증거물·탐험 지도·닮은꼴 판정단
- 몸에 붙는 겹침 창 z-index: 탐문 중 .wko 60, 같은 포즈 촬영기 .pcam 70, 확인창 .askbox 90, 알림 띠 100. 아래 창(sheet)은 11이라 겹침 창이 열려 있으면 가려짐 → 겹침 창을 닫고 열 것 (크게 본 지도 .mapfull 55는 열려 있는 동안 sheet 57·scrim 56으로 올림)
- 앨범 칸은 원본 사진(최대 1600px·약 300KB)을 작게 보여 주는 거라 사진이 아주 많아지면 데이터·메모리가 큼 → 썸네일을 따로 저장하려면 사진 기록에 칸(thumbUrl)을 추가해야 해서 사용자 확인 후
- 맨 위로 단추(.totop, 2026.10.29 사용자 요청): main-boot.js 맨 끝 — 500px 넘게 내리면 오른쪽 아래(탭 바 위)에 동그란 ↑ 단추, '+ 사진 올리기' 같은 .fab이 있으면 그 바로 위로 자동으로 올라감(고정 위치 요소라 offsetParent 말고 getClientRects로 확인). 편집창·탐문·크게 보기·사진 고르기 중엔 숨김, z-index 7

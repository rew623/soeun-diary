# 예방접종·검진·발달·급식·긴급 출동

기능별 자세한 설명과 지금까지의 결정(사용자 요청 이유). 이 영역을 고칠 때만 읽고, 고친 뒤 이 파일만 고쳐요.

- hospitals.js: 긴급 출동 탭의 소탭 🏥병원·💊약국(S.sickView 'hosp'|'ph', 탭 안에 바로 HOSP.render(true) — 2026.10.11 사용자 요청, 응급실 소탭은 없애고 병원 안 '🚑 응급실·야간 진료 병원만 보기' 단추 H.preset 'ernight'. HOSP.open(preset, kind)도 이 소탭으로) (강원 18개 시·군, 현재 위치의 시·군 자동 선택, 카카오맵(크게 보기), 목록, 필터, 관심 병원·약국, 공휴일 목록)
- recipes.js: 급식 수사 > 센터 식단 올리기 (엑셀 → 표준레시피, PDF → 식단표 이미지, 사진)
- dev.js: 예방접종 탭 > 발달 체크(S.vacView='dev'), 2~24개월 8단계(CDC 발달 이정표 참고), dev 컬렉션
- checkups.js: 예방접종 탭 > 영유아검진 (검진 8회 + 구강검진 3회 일정을 태어난 날로 계산)
- 서류함(2026.10.17 사용자 요청 '보험 청구용 서류'): claims.js — doc 컬렉션(docs/data.md). 긴급 출동 탭 맨 위 '🧾 서류함' → S.view='claims': 종류(약봉지·처방전·영수증·진료확인서·세부내역서·검진결과·접종확인·증상사진·기타)·청구 상태(미청구·청구함·지급완료) 거름망, 사진 크게 보기, 금액·날짜·메모 고치기, 여러 장 골라 '📤 공유·저장'(navigator.share 파일 여러 개, 안 되면 다운로드)·'청구함으로/지급완료로' 일괄 변경, '＋ 서류 올리기'. 편집창에도 📎 칸(CLAIM.field(link, 기본종류, 날짜) + 저장 뒤 CLAIM.flush(link)): 증상·체온·투약 기록(log:id), 진료(visit:id), 접종(vac:id), 영유아검진(chk:id). 사진은 한 문서에 한 장, 400KB 이하로 줄여 Storage에. 증상 기록엔 '완료 시각'(log.until, 걸린 시간 표시)도 추가
